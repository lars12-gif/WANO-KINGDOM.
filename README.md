# WANO KINGDOM APK

مشروع أولي لتطبيق Android يجمع أربع أدوات في واجهة واحدة:
1. فاحص الأرقام
2. حسبة الوورك
3. حسبة ADS
4. نقاط الترقية

التصميم أسود وبنفسجي، مع صفحة إعدادات ومعلومات.

## بناء APK من الهاتف عبر GitHub
1. أنشئ مستودع GitHub جديداً.
2. ارفع جميع ملفات هذا المشروع إلى المستودع، مع إظهار الملفات المخفية حتى يظهر مجلد `.github`.
3. افتح تبويب Actions.
4. شغّل `Build WANO KINGDOM APK` بواسطة Run workflow، أو ادفع commit إلى فرع main.
5. بعد نجاح البناء افتح تشغيل الـ workflow ثم قسم Artifacts ونزّل `WANO-KINGDOM-debug-apk`.

## ملاحظات
- هذا مشروع مصدر، وليس APK مبنياً مسبقاً.
- البناء يحتاج نجاح GitHub Actions؛ لم يتم تأكيد إنشاء APK بعد.
- قاعدة فاحص الأرقام محلية وتعرض المطابقة مع القائمة فقط، ولا تتحقق من حالة الحظر الفعلية في واتساب.
- راجع النتائج على عينات حقيقية قبل الاعتماد التشغيلي، خصوصاً تنسيقات رسائل الوورك وADS.
- حزمة التطبيق الحالية `org.wano.kingdom.wanokingdom` (domain + package.name).

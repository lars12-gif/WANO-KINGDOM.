# WANO KINGDOM — نسخة الويب القابلة للتثبيت

## رفع المشروع من الهاتف إلى GitHub
1. فك ضغط ملف ZIP.
2. افتح مستودعك على GitHub.
3. ارفع محتويات المجلد إلى جذر المستودع (وليس مجلد ZIP نفسه).
4. من Settings → Pages.
5. اختر Deploy from a branch، ثم Branch: main والمجلد: /(root)، واضغط Save.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages.
7. افتح الرابط في Chrome على أندرويد، ثم ⋮ → إضافة إلى الشاشة الرئيسية / تثبيت التطبيق.

## الملفات
- index.html: التطبيق والأدوات الأربع.
- manifest.webmanifest: بيانات التثبيت.
- sw.js: التخزين المؤقت والعمل دون اتصال بعد أول تحميل.
- icon.svg: أيقونة التطبيق.

## ملاحظات
- فاحص الأرقام يبحث في قاعدة البيانات المضمّنة والأرقام التي تضيفها يدوياً، ولا يتصل بواتساب.
- يمكنك إضافة رقم وتصنيفه وملاحظته، ثم تعديل الإضافة أو حذفها من داخل الأداة.
- الأرقام المضافة تُحفظ في مساحة التخزين المحلية للمتصفح على نفس الجهاز؛ مسح بيانات الموقع أو استخدام متصفح/جهاز آخر قد يزيلها ولا ينقلها تلقائياً.
- الحسابات تتم محلياً داخل المتصفح ولا يتم إرسال النصوص إلى خادم.
- حافظ على أسماء الملفات ومكانها في جذر المستودع.


تم تحديث الهوية البصرية إلى الأسود والأحمر، وإضافة أيقونة ملكية جديدة بصيغ PNG بأحجام 192 و512.
